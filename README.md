# 棋谱工作台（XQ Record Workbench）

一款用 Python + 原生 Tkinter 编写的中国象棋棋谱管理软件，目标是全面替代 XQStudio 1.63 的常用功能：

- **XQF 读写**：打开、编辑、另存中国象棋标准棋谱文件（.XQF）
- **文本导入**：支持将文本棋谱导入为 XQF；**真合并**（相同前缀共用、不同处分支）
- **单线路 + 变着显示**：完整呈现棋谱树，支持变着分支
- **云库查询**：查询当前局面的 FEN 与引擎分数
- **按局面检索棋谱库**（Ctrl+F）：导出当前棋盘的棋子位置，遍历整个棋谱库（含子目录、含变着），按局面匹配并列出命中棋谱与匹配着数；单击预览，双击在主窗口打开并跳到匹配着

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `xqdesk.py` | 主程序：主窗口、棋盘、菜单、工具栏，启动入口 |
| `xqfind.py` | 查找模块：按局面/条件检索棋谱库（扫描只读，不修改用户棋谱） |
| `xqf.py` | XQF 文件解析（读取棋谱树） |
| `xqf_write.py` | XQF 文件写出（保存棋谱树） |
| `xqf_import.py` | 文本棋谱导入、真合并逻辑 |
| `xqconvert.py` | 命令行批量转换工具 |
| `使用说明.txt` | 功能与操作说明 |

## 运行

需要 Python 3（仅用标准库，无需安装依赖）：

```
python xqdesk.py
```

## 检索使用

1. 菜单「文件 → 查找浏览 XQF 文件…（Ctrl+F）」或工具栏「查找棋谱」打开查找窗口
2. 选择要扫描的文件夹，勾选「包含子目录」
3. 可在棋盘上右键「导出棋子位置到查找窗口」，自动填入局面并扫描
4. 结果列表中单击预览、双击打开并跳到匹配着

注意：检索全程只读，不会修改或覆盖任何棋谱文件。
