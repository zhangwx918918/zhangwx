棋谱工作台 —— 使用说明
========================

一、启动
  双击「启动棋谱工作台.bat」即可打开界面（无需安装，使用本机 Python）。
  也可命令行：python xqdesk.py

二、界面（参考棋谱网页版）
  · 三栏：左＝棋图，中＝棋谱树，右＝注解。拖动栏间分隔条即可调宽窄。
  · 三个滑块：棋谱字号、注解字号、棋盘大小，各自独立可调。
  · 输入棋谱：点击棋盘上的棋子，再点目标格即走子；红黑自动交替。
  · 变着：走到某步后另走一着，自动成为该步的变着（树中缩进显示「└变」）。
  · 注解：选中某步，在右栏输入文字，点「写入本步」；整局注解在下方。
  · 播放：|◀ 首步 / ◀ 上一步 / ▶ 自动 / ▶ 下一步 / ▶| 末步；键盘 ←/→/Home/End 亦可。
  · 删除本步：移除当前着法及其后续。

三、文件菜单 / 工具栏按钮
  · 打开 / 保存 / 另存为 / 新建：标准 XQF 读写（编辑已有文件会原样保留棋头）。
  · 导入文本：把 txt/chn/ccm/mxq/che 等中文着法文本读入为新棋局，再「另存为」XQF。
  · 合并XQF：可多选文件。与当前谱真合并——相同着法共用，从着法不同处
    才分出新变着（与原 XQStudio 一致），不会把每局重复罗列。
  · 批量转换：选一个文件夹，把其中所有非 XQF 文本棋谱批量转成 XQF。
  · 查找棋谱（Ctrl+F）：打开「查找浏览 XQF 文件」窗口，选文件夹（可含子目录），
    按文件名称/红黑方棋手/比赛结果检索整个棋谱库。
  · 导出棋子位置到查找窗口：在棋盘上点右键选此项（或查找窗口里点「使用当前局面」），
    自动扫描库中所有棋谱的全部线路（含变着），只列出出现过当前局面的棋谱，
    并标明匹配在第几着。单击结果预览局面，双击在主窗口打开并跳到匹配的那一步。
    与原 XQStudio 的同名功能一致。扫描只读，不改动任何棋谱文件。
  · 云库FEN：把当前局面编成象棋云库(chessdb.cn) FEN 码，自动复制到剪贴板
    并在浏览器打开云库查询页（局面已带入）。轮走方按上一着颜色自动判断。
  · 云库分数：直接联网查询当前局面的云库分数，弹窗列出候选着法（中文着法、
    分数、等级、胜/和/负率），最佳着法高亮；状态栏显示摘要。分数为正利于走子方。

四、命令行工具（不开界面）
  python xqconvert.py convert  输入.txt  输出.xqf
  python xqconvert.py batch    文件夹  [输出文件夹]
  python xqconvert.py merge    主谱.xqf  其它.xqf  输出.xqf

五、关于格式
  · 文本导入支持中文着法（炮二平五 / 马8进7 / 前马退六 等）、回合号、
    括号或方括号注解；自动识别 UTF-8 / GBK 编码。
  · 合并默认双方均为标准开局（XQF 每文件仅一个初始局面）。
  · 纯二进制旧格式（部分 .che/.mxq）若不含中文着法文本，会提示无法识别，
    需要该格式样本才能进一步支持。

六、文件清单
  xqdesk.py      界面主程序
  xqf.py         XQF 解析（读）
  xqf_write.py   XQF 生成/编辑/合并（写）
  xqf_import.py  文本棋谱解析与转换
  xqfind.py      查找浏览 XQF 文件（按局面/条件检索棋谱库）
  xqconvert.py   命令行工具
  启动棋谱工作台.bat  启动器
